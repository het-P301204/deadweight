# atlas-triage (synthetic)

A fabricated service used to demonstrate DEADWEIGHT. Nothing here is real: no
real weights, no real credentials, no real endpoints, no real customer. The
binary artifacts under `weights/` and `models/` are generated by
`scripts/make-fixtures.ts` and are the smallest byte sequences that are
genuinely recognisable as each format.

It exists so that a person can see the product working on a project that
contains one of every situation the analyser has an answer for:

- a pickle loaded in a request handler that also holds cloud credentials
- a `torch.load` with no `weights_only`, against a torch pin that spans the
  release where the default changed
- a `torch.load` that passes `weights_only=True`
- a `.bin` checkpoint loaded while a `.safetensors` of the same weights sits
  next to it in the repository
- weights loaded from safetensors, ONNX and GGUF
- `trust_remote_code=True`
- a remote model reference with no format requirement
- a Keras load against a Keras 2 pin
- `numpy.load` with `allow_pickle=True`
- `yaml.load` with no Loader
- a load target built at run time
- a file whose extension disagrees with its bytes
- an artifact in the tree that nothing in the tree loads
- an unrecognised container format
- an MCP manifest that spawns a process, and one that does not
- a skill, an agent definition, a hook and a prompt template
- scanner evidence that binds, scanner evidence that has gone stale, and an
  executing artifact with no evidence at all
